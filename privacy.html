隱私權政策

生效日期：2026 年 11 月 16 日

重點：CirraFold 只在你的電腦上執行。你的檔案與帳號資料只在「你的電腦」和「Google」之間傳輸，開發者收不到任何資料。

1. 適用範圍

本政策說明 CirraFold Windows 桌面程式（以下稱「本程式」）如何存取、使用、儲存你的 Google 帳號資料。不論你使用本程式的內建 Google Cloud 專案，或使用你自己建立的 Google Cloud 專案，本政策都適用。

2. 本程式存取的 Google 資料

你登入 Google 帳號並同意授權後，本程式會存取：

  • 帳號基本資訊：電子郵件地址、Google 帳號的識別碼。用來在本程式中分辨不同的帳號。
  • 儲存空間用量：已使用與總容量。用來決定新檔案要放在哪一個帳號，並顯示給你看。
  • Google 雲端硬碟的檔案與資料夾：名稱、大小、修改時間、檔案內容。用來上傳、下載、改名、搬移，以及把檔案移到垃圾桶。
    • 使用內建專案時，本程式只能存取它自己建立的檔案（權限範圍 drive.file）。
    • 使用你自己的專案、並選擇管理既有檔案時，本程式可以存取該帳號雲端硬碟中的所有檔案（權限範圍 drive）。

3. 資料如何使用

  • 這些資料只用來提供本程式的同步與檔案管理功能：在檔案總管中顯示雲端的檔案、需要時下載、把本機的變更同步到雲端。
  • 本程式不會把資料用於廣告、不會出售、不會用來做信用評估，也不會讓任何人閱讀你的檔案內容。
  • CirraFold 對於從 Google API 取得之資訊的使用，以及將這些資訊傳輸到任何其他應用程式的行為，都會遵守 Google API 服務使用者資料政策，包括其中的「有限使用」（Limited Use）規定。

4. 資料儲存在哪裡

本程式沒有自己的伺服器。所有資料都只存在你的電腦上（Windows 的 %LOCALAPPDATA%\CirraFold 資料夾）：

  • 登入授權（OAuth token）：用 Windows 的資料保護機制（DPAPI）加密，只有你的 Windows 帳號能解開。
  • 檔案索引：每個檔案的路徑、大小、所在帳號、Google 雲端硬碟的檔案識別碼、內容的雜湊值（MD5）。
  • 設定與記錄檔：記錄檔可能包含檔案路徑與帳號電子郵件，用來排除問題，只存在你的電腦上，不會自動傳送給任何人。
  • 檔案內容：只有你選擇保留在本機、或正在開啟的檔案，內容才會存在你電腦上的 CirraFold 同步資料夾裡。

5. 資料傳輸與分享

  • 本程式只和 Google 的伺服器通訊（透過 HTTPS 加密連線）。
  • 本程式不收集使用統計、不傳送當機報告，也沒有任何追蹤功能。
  • 開發者收不到、也看不到你的檔案、帳號資訊或使用紀錄，所以不會和任何第三方分享你的資料。

6. 你的控制權

  • 撤銷授權：隨時可以在 Google 帳戶的「第三方連線」頁面 移除 CirraFold 的存取權。
  • 刪除本機資料：解除安裝本程式，並刪除 %LOCALAPPDATA%\CirraFold 資料夾，就會刪除所有本機儲存的授權、索引、設定與記錄。
  • 雲端的檔案：存放在你自己的 Google 帳號裡，停止使用本程式也不會被刪除。本程式在本機刪除檔案時，雲端的處理方式是移到 Google 雲端硬碟的垃圾桶（30 天內可以還原），不會永久刪除。

7. 兒童

本程式不是為 13 歲以下的兒童設計，也不會刻意收集兒童的資料。

8. 政策變更

本政策若有變更，會更新本頁面並修改上方的生效日期。重大變更會在本程式的新版本中提醒你。

9. 聯絡

對本政策有任何問題，請到 GitHub Issues 留言。
