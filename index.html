在檔案總管裡，統一管理多個 Google 雲端硬碟帳號

CirraFold 是 Windows 桌面程式。你的多個 Google 帳號，在檔案總管裡就是一個普通的資料夾，不必在瀏覽器裡切換帳號。

功能

  • 一個資料夾管理多個帳號：檔案總管左側有一個 CirraFold 資料夾，用法和一般資料夾一樣。
  • 隨選下載：檔案平常只在雲端，不佔本機空間；打開時才下載。
  • 一律保留在此裝置上：常用的檔案或資料夾可以固定留在本機，沒有網路也能開啟。
  • 帳號群組：新檔案依你選的規則放到群組裡的某個帳號，例如同一個資料夾的檔案放在同一個帳號。
  • 刪除可以復原：在本機刪除的檔案，雲端是移到 Google 雲端硬碟的垃圾桶（30 天內可以還原），而不是永久刪除。一次刪除大量檔案時，會先暫停，等你確認。

運作方式與你的資料

  • CirraFold 完全在你的電腦上執行。檔案只在「你的電腦」和「Google 的伺服器」之間傳輸。
  • 開發者沒有任何伺服器，也收不到你的檔案、帳號資訊或使用紀錄。
  • 登入授權（token）用 Windows 的加密機制（DPAPI）存在你的電腦上，只有你的 Windows 帳號能解開。
  • Google 登入畫面上顯示的專案名稱，只是讓 Google 知道是哪一個程式在存取你的雲端硬碟。

詳細內容請見 隱私權政策。

兩種使用方式

  • 內建專案（一般使用者）：只能存取 CirraFold 建立的檔案，看不到帳號裡原本就有的檔案。
  • 使用你自己的 Google Cloud 專案（進階）：可以選擇讓 CirraFold 管理帳號裡原本就有的檔案，並同步你在網頁或手機上做的變更。程式內的設定精靈會一步一步引導你建立。
